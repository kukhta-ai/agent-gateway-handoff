## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Provide a single deterministic graph projection for selected providers, template defaults, compatibility, dependency availability, and config precedence.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 A graph projection can be built from a provider set, base profile, approved overlays, provider manifests, template packages, dependency requirements, and current dependency evidence.
- [ ] #2 Unknown provider ids, family mismatches, duplicate provider versions, overlay cycles, unresolved relations, unavailable host-touching dependencies, and ambiguous required compatibility are rejected with stable diagnostics.
- [ ] #3 Config and default precedence follows the documented order from provider schema defaults through runtime AssemblySpec params.
- [ ] #4 WPM DependencyBinding evidence is treated as dependency evidence rather than ordinary provider config.
