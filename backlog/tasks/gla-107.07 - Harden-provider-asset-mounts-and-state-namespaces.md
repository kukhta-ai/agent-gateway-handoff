## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Give provider-owned browser assets and provider-owned state the same fail-closed graph discipline as runtime providers.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 Provider asset mounts are namespaced by provider id and reject path collisions, traversal, mutable roots, and paths that overlap grant, enrollment, callback, route, or other provider asset surfaces.
- [x] #2 Gateway-served provider assets preserve required security headers and reject raw grants, bootstrap tickets, secret refs, operator tokens, or generated runtime config in reviewed asset inputs.
- [x] #3 Provider state namespaces carry provider id, schema version, sensitivity classification, migration behavior, and redacted diagnostics.
- [x] #4 Unknown provider state schema versions fail closed during daemon recovery before public gateway traffic is bound.
<!-- AC:END -->
