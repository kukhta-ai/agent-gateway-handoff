## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 The reference provider set exposes named profiles for local development, single-operator self-hosting, scenario-01, and hardened delegated-identity posture, or equivalent documented names.
- [ ] #2 Each named profile selects concrete provider ids and template defaults that validate as available or unavailable with actionable diagnostics in the current environment.
- [ ] #3 Documentation and catalog/read-model output identify which profile a default provider choice belongs to when naming WebAuthn, authentik, process launcher, Docker, CLI channel, Telegram, or equivalent alternatives.
- [ ] #4 Changing the selected profile is an operator boot configuration change and does not require edits to generic app composition.
