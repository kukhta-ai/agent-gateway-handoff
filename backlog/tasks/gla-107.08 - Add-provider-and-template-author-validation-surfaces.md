## Acceptance Criteria

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Implemented provider/template authoring validation and skeleton surfaces in @gla/catalog. Provider validation now reports stable diagnostics for manifest, family contract, schema, probe, skills/docs, dependencies, WPM bundle/skeleton handoff, redaction, contract tests, and narrow-waist edits. Template validation reports stable diagnostics for TemplatePackage/catalog entity, schema, defaults, compatibility, skills/docs, template dependencies, WPM handoff, redaction, factory-forbidden, and narrow-waist edits. Skeleton creators return authoring-only changed-file lists and readiness reports with availability=not-evaluated and nextUx=operator-install-update. Path traversal and unsafe ids are rejected before skeleton paths or changed-file boundaries can escape package scope.
