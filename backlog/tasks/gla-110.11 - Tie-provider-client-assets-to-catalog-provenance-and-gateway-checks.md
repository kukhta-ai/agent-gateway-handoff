## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Make browser-facing provider assets part of the provider capability/evidence story instead of an implicit provider-set callback or unchecked local override.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 Entrypoint client assets served by the gateway are traceable to a registry/catalog provider capability or an explicit local override with visible provenance.
- [x] #2 The catalog or doctor surface reports whether a client asset source is packaged, evidence-backed, local override, read-only, mutable, or unverifiable.
- [x] #3 A mutable or unverifiable alternate client asset root cannot be mistaken for packaged immutable provider evidence in runtime diagnostics.
- [x] #4 Gateway behavior is covered for packaged assets, alternate asset roots, writable roots, missing roots, and evidence-backed asset sources.
<!-- AC:END -->

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
2026-06-16: Started after GLA-110.10 completed and merged. Scope is browser-facing provider asset provenance and mutability: catalog/doctor visibility for packaged, evidence-backed, local override, read-only, mutable, missing, and unverifiable asset sources; gateway behavior coverage for those states; and preventing local overrides from appearing as packaged immutable evidence.

2026-06-16: Implemented provider client asset provenance through catalog/doctor/read models and runtime composition. App composition now derives client asset exists/verified/readOnly facts from filesystem roots before provider-graph projection; missing local overrides report missing/unverifiable instead of ready, mutable local/WPM roots report mutable, and local overrides do not inherit package evidence from declarations. Gateway checks cover packaged, local override, WPM evidence, missing, writable, and unsafe refs; noVNC preserves GLA_NOVNC_WEB_ROOT as an explicit local override. Focused verification passed: 7 files / 168 tests. Full pnpm run gate passed: typecheck/build, Biome CI, required browser preflight, 82 files / 923 passed / 15 skipped. Independent Goodall re-review APPROVE after final false-ready and package-marker fixes.
<!-- SECTION:NOTES:END -->
