## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Create a distinct app deployment selection model for providers that run the app itself, while keeping capsule provider choices in assembly/template composition.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 The app exposes a deployment configuration surface for AuthProvider, ChannelAdapter, SecretStore, and their app-level defaults without including Launcher, Workspace, HumanEntrypoint, AgentConnector, or CompletionDetector selections.
- [ ] #2 Capsule assembly and template inputs expose Launcher, Workspace, HumanEntrypoint, AgentConnector, and CompletionDetector choices without carrying AuthProvider, ChannelAdapter, or SecretStore selections.
- [ ] #3 Runtime provider-id overrides preserve named deployment defaults, provider configuration, and SecretStore selection instead of rebuilding a synthetic profile that drops them.
- [ ] #4 Enrollment policy parsing and diagnostics use the resolved deployment AuthProvider selection, including profile-selected delegated auth providers without requiring the legacy auth-provider flag.
- [ ] #5 The existing reference scenarios are expressible as app deployment configuration plus capsule composition defaults, with unchanged externally observable defaults.
<!-- AC:END -->

## Definition of Done
<!-- DOD:BEGIN -->
- [ ] #1 Typecheck passes with no errors.
- [ ] #2 Linter passes clean.
- [ ] #3 Tests are added for the change and the full suite is green.
- [ ] #4 Public functions and exported types are documented.
- [ ] #5 No dead code or unused exports are introduced.
- [ ] #6 The core import-boundary holds: core depends only on ports, never on concrete adapters.
- [ ] #7 Reference fixtures or scenarios show app deployment provider selection and capsule provider selection as separate serialized inputs.
- [ ] #8 Delegated-auth enrollment policy behavior is verified through the resolved deployment AuthProvider selection without the legacy auth-provider flag.
- [ ] #9 Runtime override coverage proves named deployment defaults, provider configuration, and SecretStore selection survive capsule provider overrides.
